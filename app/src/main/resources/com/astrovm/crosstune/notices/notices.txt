# Every work by others that Crosstune ships or downloads, shown in Settings → About → Licenses.
# One block per work, apart by a blank line: its name, then "key: value" lines.
#   by       who made it
#   license  its licence, by name
#   text     files in this folder with the licence's full text and notices, shown one after the other
#   url      where it, or its source, is; opened in the browser only on a tap
#   note     what Crosstune changed, or what else the licence asks to say
#   covers   what of the APK it is, for the :app:notices task, which fails the build on anything not covered
#            and on a line that covers nothing. One per line:
#              maven GROUP:MODULE     a library in the release APK, * for any part of a name
#              submodule PATH         a Git submodule built into the APK
#              file PATH              a bundled file, * for any name in one folder, ** for anything under it
# Licence texts are copied from each work's own LICENSE or NOTICE file, never written by hand.
