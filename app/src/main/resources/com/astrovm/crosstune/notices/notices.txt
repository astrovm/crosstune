# Every work by others that Crosstune ships or downloads, shown in Settings → About → Licenses.
# One block per work, apart by a blank line: its name, then "key: value" lines.
#   by       who made it
#   license  its licence, by name
#   text     files in this folder with the licence's full text and notices, shown one after the other
#   url      where it, or its source, is; opened in the browser only on a tap
#   note     what Crosstune changed, or what else the licence asks to say
#   covers   what of the APK it is, for the :app:notices task (in :app:ci), which fails on anything in the
#            release APK no line covers, and on a line that covers nothing. One per line, exact, no wildcards
#            unless said:
#              maven GROUP:MODULE          a library in the release APK
#              maven GROUP:MODULE!PATH     a licence or notice file inside that library
#              file PATH                   a bundled file or a file dependency; * for any name in one folder
#              submodule PATH              a Git submodule built into the APK
#              source PATH                 a compiled native source or header; * and ** as in file
#              source PATH ~ WORDS         the licence or origin lines in that file that hold WORDS; each such
#                                          line in a compiled file needs one
#              native NAME                 a library the NDK links into the native code
#              download URL                a file the app downloads, as its code names it
# Licence texts are copied byte for byte from where each work publishes it; notice-texts.txt in the
# tests says where, and scripts/notices.py checks it.
