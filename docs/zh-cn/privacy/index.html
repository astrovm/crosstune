Crosstune 隐私政策

最后更新：2026年11月20日

简要说明

  • 没有账号、广告或数据分析。
  • 你的历史记录只保存在你的手机上。Crosstune 唯一的服务器只接收你发送的问题报告。
  • 你转换的链接只会发送到相关的音乐服务。
  • 识别歌曲时，Shazam 只会收到声音的指纹，绝不会收到音频。
  • 随时可以在应用中清除历史记录。
  • AI 功能是可选的。只有在你用 ChatGPT 登录后，才会把歌词发送给 OpenAI。

详细说明

Crosstune 是由 astrovm 开发的 Android 应用，可以在你选择的应用中打开音乐链接，并显示你正在播放的歌曲的歌词。本页说明应用会使用哪些信息，以及这些信息会发送到哪里。

没有账号、广告或数据分析

Crosstune 没有账号、广告、数据分析或崩溃报告，也不会出售你的信息。开发者唯一的服务器只接收你选择发送的问题报告，详见下文。其他所有请求都从你的手机直接发送到这里列出的服务。和任何请求一样，该服务会看到你的 IP 地址，并按自己的隐私政策处理。

你的手机上

你的设置、最近的歌曲、保存的行和练习卡留在你的手机上，不纳入 Android 的备份。你保存以便离线使用的歌曲，会把歌词、翻译、和弦和封面留在手机上，只在 Wi-Fi 下下载。Crosstune 只在你打开、分享或粘贴链接时读取链接，只在你使用粘贴快捷方式时读取剪贴板。它会检查安装了哪些音乐应用，以便提供给你选择。

打开链接

为了识别链接里的歌曲，Crosstune 会读取该链接所属服务的公开页面或 API：Spotify、YouTube、YouTube Music、Apple Music、Deezer、TIDAL、SoundCloud、Bandcamp、Audiomack、Shazam 或 Google，并加载它的封面。为了在其他应用中打开，标题和艺人会发送到该应用的搜索。当这个搜索拿不准时，它们还会发送到 Apple 和 Deezer 的歌曲搜索。对于 Spotify，它们会发送到 ListenBrainz，艺人的名字发送到 MusicBrainz，并读取 Spotify 的公开页面。“全部播放”和“随机播放”会对每首歌这样做，YouTube 用找到的视频生成播放列表。你输入的歌名会发送到 Deezer 和 Apple 的搜索。自定义目标会在你设置的网址中收到搜索词。

歌词、和弦和翻译

歌曲的标题和艺人会发送到 LRCLIB、YouTube Music、网易云音乐、Letras 和 Genius 来查找歌词，发送到 Ultimate Guitar、Cifra Club、LaCuerda、U-FRET、J-Total 和 ChordWiki 来查找和弦，发送到 Apple 来查找翻唱歌曲的原曲，发送到 UtaTen 来获取日语歌曲的读音。你翻译的行会发送到 Google Translate 或 MyMemory，你查词的词语会发送到它们或 Wiktionary。已经是你的语言的歌词不会被发送。读音在你的手机上生成。ChordWiki 会在隐藏的浏览器页面中打开，该页面会运行脚本，可以在应用的浏览器存储中保存 Cookie，也可能连接 Cloudflare 和 Google。来自 Maven Central 的日语词典和来自 Hugging Face 的语音模型只在 Wi-Fi 下下载一次。

跟随你的音乐

有了通知使用权，Crosstune 能看到你的音乐应用正在播放哪首歌以及播放到哪里，让歌词跟着走，播放器也能在你的应用里暂停、切歌或点赞。对于 Simple Radio，它还会检查电台的媒体通知是否在显示，但不读取通知的文本。这些只留在你的手机上。练习卡会在已经打开这首歌的应用里播放那一行，或在卡片上的小 YouTube 播放器里播放；它像链接一样查找歌曲的视频。你没有在那里登录 YouTube。

聆听

Crosstune 只在你识别歌曲时、歌词打开或悬浮时，以及你允许麦克风之后，在 Crosstune 打开且播放的应用没有说明是哪首歌时聆听。它听的是你的手机播放的声音，使用 Shizuku 或 root 时更清晰，只有手机不共享声音时才使用麦克风。Android 会显示麦克风已开启。发送给 Shazam 的只有声音的指纹，绝不包括音频，Shazam 会返回歌曲。之后会向 Apple 询问这段录音的时长。离线时，指纹会留在应用内存中，直到你重新联网。如果无法连接 Shazam，会改为打开 Shazam 或 Google 应用（如果你装了）。

让歌词对上歌声、给没有时间轴的歌词定时，以及检查一首歌有没有人在唱，都在你的手机上完成，不会发送任何内容。MilkDrop 视觉效果也会读取声音，以便跟着它动。声音从不保存。

ChatGPT

AI 功能是可选的，需要你自己的付费 ChatGPT 套餐。你在 OpenAI 的网站上登录。登录信息保存在你的手机上，不纳入备份，并且只发送给 OpenAI。登录期间，OpenAI 会收到每个功能所需的内容：歌曲、它的歌词、你询问的词和行，以及你输入的描述。当歌曲搜索拿不准时，歌曲的标题、艺人和搜索结果也会发送给 OpenAI，以便它选出正确的一首。歌曲的释义还会向 MusicBrainz 询问发行年份和专辑。

投放到电视

在 Google Play 和 GitHub 版本中，你可以把歌曲投放到 Android TV 或 Google TV 上的 Crosstune。Google Cast 是 Google Play 服务的一部分，它在你的本地网络中查找电视并负责投放。投放时，Crosstune 会把歌曲的标题、艺人、链接和封面发给电视，之后再发你的操作：暂停、播放、跳过、拖动、翻译和注音。电视会告诉你的手机它正在播放什么。这些只在你的手机和电视之间传递，绝不会发给开发者，Google 按其自己的隐私政策处理。没有 Google Play 服务的版本没有投放功能，也不会发送此类内容。

问题报告

在歌词里点“报告问题”，再点“发送”，会把你写的内容、Crosstune 和 Android 的版本，以及这首歌的歌名、歌手和时长、歌词的来源和对时方式、你手动对时的每一行的歌词和时间（最多发送最能说明问题的 300 行，为了不超过 48 KB 可能更少），以及 Crosstune 正在跟随的应用发送到开发者的服务器。如果报告与对时有关，还会发送播放这首歌的应用的包名、该应用的播放速度、Crosstune 把歌词提前显示多少，以及 Crosstune 自己最近一分钟的对时记录，其中有 Shazam 给这段录音的编号。其中没有任何关于你、你的其他应用或你的手机的信息。服务器运行在 Cloudflare 上，Cloudflare 按自己的隐私政策处理这次连接，包括你的 IP 地址。服务器不保存你的 IP 地址。为了限制同一网络能发送多少报告，服务器会用密钥，由地址中表示网络的部分生成代码，记下当天的报告数，并在第二天删除这些计数；数据库的备份最多还会再保留 30 天。没有密钥，就无法从代码追溯到网络。只有开发者会看报告，报告绝不会公开。每份报告会在 180 天后删除，数据库的备份最多还会再保留 30 天。如果你在设置中打开“自动报告歌曲问题”，或在 Crosstune 提出时选择“好”，Crosstune 会在发现歌曲没有歌词、没有时间或没有和弦时，在你手动为歌词对时后，或在听到的演唱与歌词对不上时，发送同样的信息，不含评论，每首歌只发送一次。你手动对时的内容会留在手机上等到那时，无论你怎么回答。旧版 Crosstune 保存的时间也会各发送一次：歌名、录音和时长、各行的时间，以及是否听到了歌声。Crosstune 发现的问题和你手动对时的歌词，每天合计最多发送 23 个，其余的留在手机上，等以后某天再发。Crosstune 自动发送的报告如果没送到，会留在手机上，等到下次启动：手动对时的最近 20 个、发现的最近 20 个问题，以及旧版保存的所有时间。服务器始终不接受的报告会被删除，不再发送。从这个版本起保存的报告各带一个随机 ID，只为这份报告生成，不包含关于你或你手机的任何信息，因此即使同一份报告送到两次，服务器也只保存一次。关闭自动报告后，等待中的已发现问题会被删除；你手动对时的歌词和旧版保存的时间会保留，等你重新打开自动报告后才会发送。你点“发送”自己发出的报告不会保存：没送到时，Crosstune 会告诉你。原样再发一次，发出的是同一个 ID，所以只保存一次。在设置中，“报告问题”则会打开一个 GitHub issue 或邮件，由你自己发送，GitHub 或你的邮件服务会按各自的隐私政策处理。

在词语详情里把它的读音标为有误，再点“发送”，会把这个词、显示的读音、生成它的来源（比如手机上的词典、歌词本身或 ChatGPT）、它所在的整行歌词、它的文字、你输入的正确读音（如有）、这首歌的歌名和歌手、歌词的来源、Crosstune 和 Android 的版本，以及只为这份报告生成的随机 ID 发送到同一台服务器。它会像上面的报告一样保存和阅读。

权限

Crosstune 使用网络，以及网络状态来判断你何时离线。第一次识别歌曲或打开歌词时，它会请求麦克风权限。通知使用权让歌词跟随你的音乐。悬浮歌词会请求显示在其他应用上层的权限和显示通知的权限。练习提醒会请求显示通知的权限，并在重启后重新设置每日闹钟。Crosstune 不会请求位置、相机、通讯录或广告 ID 权限。使用 Shizuku 或 root 时，它只为 Crosstune 更改这些设置，并让歌词能听到音乐应用播放的声音。内置的请求均使用 HTTPS，所以自定义目标请选择 HTTPS 地址。

浏览器扩展

适用于 Chrome、Edge、Brave 和 Firefox 的扩展只在它支持的音乐网站上工作。它会把链接的标题和艺人发送到应用发送的地方，并且只在歌词侧边栏打开时，也发送到 LRCLIB、YouTube Music、网易云音乐、Letras 和 Genius。它的设置保存在你的浏览器里，也不向开发者发送任何内容。

删除你的数据

在应用中清除历史记录，或在 Android 设置中清除 Crosstune 的存储空间，即可删除它保存在你手机上的所有内容。开发者没有关于你的账号或历史记录。报告里没有任何能看出是谁发送的信息，所以无法按请求找到某份报告来删除。Crosstune 连接的服务会按各自的政策保存它们收到的请求。

儿童

Crosstune 不会询问你的年龄，也不会有意收集儿童的信息。它打开的音乐服务有各自的年龄要求和隐私政策。

联系方式与变更

如有隐私方面的问题，请联系 crosstune@4st.li。你的邮件服务会处理你的地址和邮件内容，以便开发者回复。本政策会随应用一起变更，并在此页面注明新的日期。
