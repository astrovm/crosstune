Crosstune 隐私政策

最后更新：2026年10月30日

简要说明

  • 没有账号、广告或数据分析。
  • 你的历史记录只保存在你的手机上。Crosstune 唯一的服务器只接收你发送的问题报告。
  • 你转换的链接只会发送到相关的音乐服务。
  • 识别歌曲时，Shazam 只会收到声音的指纹，绝不会收到音频。
  • 随时可以在应用中清除历史记录。
  • AI 功能是可选的。只有在你用 ChatGPT 登录后，才会把歌词发送给 OpenAI。

详细说明

Crosstune 是由 astrovm 开发的 Android 应用，可以在你选择的音乐应用或网站中打开音乐链接。本政策说明应用会使用哪些信息，以及这些信息会发送到哪里。

没有账号、广告或数据分析

Crosstune 不需要账号，也不包含广告、数据分析或崩溃报告服务。开发者没有运营任何接收你的音乐链接或收听记录的服务器。Crosstune 不会出售你的信息。开发者唯一的服务器只接收你选择发送的问题报告，详见下文。

你设备上的信息

应用会在你的设备上保存你的设置和最近解析的链接。最近的条目可能包括来源链接、标题、艺人、封面网址以及准备好的目标链接。这些偏好设置和历史记录不在应用的 Android 云备份和设备迁移规则范围内。

Crosstune 会读取你粘贴的链接、分享给它的链接，或通过 Android 链接处理打开的链接。它的剪贴板快捷方式会在你使用时读取剪贴板中的文字。它会检查设备上安装了哪些支持的音乐应用，以便将它们作为目标提供给你。这些信息只保留在你的设备上。

向音乐服务发出的请求

为了解析音乐链接，Crosstune 会向来源服务请求其公开页面或公开 API。它还会从该服务的图片服务器加载封面图片。支持的来源服务包括 Spotify、YouTube、YouTube Music、Apple Music、Deezer、TIDAL、SoundCloud、Bandcamp 和 Audiomack。 Shazam 链接通过 Apple Music 的查询读取，较早的链接会先通过 Shazam 的公开 API 读取。 分享的 Google 结果会在 Google 上打开，以读取歌曲名称。

为了直接打开该项目，应用会将该项目的标题和艺人发送到目标的搜索服务：Apple Music、Deezer、YouTube Music、YouTube、Bandcamp、TIDAL、SoundCloud、Audiomack 或 Qobuz。Spotify 上的歌曲则通过 ListenBrainz 查找：歌曲的标题和艺人会发送到 ListenBrainz，它知道 Spotify 上哪些歌曲叫这个名字，然后读取这些歌曲在 Spotify 上的公开页面。ListenBrainz 还不知道的歌曲，会在该艺人最常播放的歌曲中查找：艺人的名字会发送到 MusicBrainz，并读取该艺人在 Spotify 上的公开页面。如果链接直接在应用中打开且“立即播放”已关闭，则会改为在那里打开搜索，不会发送任何内容。当你打开目标时，所选应用或网站会收到目标链接或搜索词。在播放列表或专辑中使用“全部播放”或“随机播放”时，应用会将每首歌曲的标题和艺人发送到 YouTube Music 的搜索，然后将找到的视频列表发送到 YouTube，YouTube 会返回一个临时播放列表。在 Spotify 中，每首歌曲会在轮到它时通过 ListenBrainz 查找。你自行添加的应用和网站会通过你配置的网址模板收到搜索词。分享结果时，结果会发送给你选择的应用或接收者。

当你输入歌曲名称而不是链接时，Crosstune 会将该名称发送到 Deezer 和 Apple 的公开歌曲搜索，并显示找到的歌曲，这样即使没有链接也能打开你要的歌曲。当你请求某首歌曲的歌词或和弦时，应用会将歌曲的标题和艺人发送到无需账号或密钥的服务：歌词用 LRCLIB、YouTube Music、网易云音乐和 Letras，和弦用 Ultimate Guitar、Cifra Club、LaCuerda 和 U-FRET，并用 Apple 的歌曲搜索和歌曲页面查找歌曲的原名，或翻唱歌曲的原唱和词曲作者。在歌词中开启翻译后，应用会把歌词各行发送给无需账号的翻译服务 Google Translate，Google Translate 无法翻译时则发送给同样无需账号的 MyMemory，除非如下文所述由 ChatGPT 翻译。歌曲的语言由 Android 在你的手机上识别，已经是翻译目标语言的歌词，或是你选择不翻译的语言的歌词，都不会被发送。汉字上方假名等读音在你的手机上生成，不会发送到任何地方。你点按查看意思的词也会以同样方式发送。如果应用语言是英语，英文单词会在 Wiktionary 词典中查询。你保存的行只留在手机上。日语会从 Maven Central 下载一次更大的词典 UniDic，只在 Wi-Fi 或其他不按流量计费的网络上下载；和任何请求一样，这会让 Maven Central 看到你的 IP 地址。

如果你让歌词跟随音乐应用中正在播放的歌曲，Android 会请你允许 Crosstune 的通知使用权。Crosstune 只用它来查看你的音乐应用正在播放哪首歌以及播放到哪里，让歌词跟着走，并让你点按的那一行把歌曲跳到那里。它从不读取你的通知，这些信息也不会离开你的手机。你可以随时在 Android 设置中关闭它。当你练习已保存的行时，Crosstune 还会请你的音乐应用从那一行开始播放它所在的歌曲。Crosstune 的播放器使用同样的权限来显示歌曲和接下来播放的内容，并在你的音乐应用里暂停、切歌、跳转进度、随机播放、循环播放、按应用自己的点赞，或用睡眠定时暂停。

与其他网络请求一样，这些请求会让被访问的服务看到你的 IP 地址和常规请求信息。这些服务可能会保留请求日志，并按照各自的隐私政策处理信息。开发者无法控制它们如何处理或保存这些数据。打开音乐服务后，该服务可能会要求使用其自己的账号或订阅。

歌曲识别

当你让 Crosstune 识别歌曲时，它只在聆听期间通过麦克风录音，最长 12 秒，一找到歌曲就停止。声音会在你的手机上转换成由最响亮的点组成的指纹。发送给 Shazam 的只有这个指纹，绝不包括音频，录音也不会保存。Crosstune 不会发送你的位置。Shazam 会返回歌曲的标题、艺人、封面和 Apple Music ID，然后 Crosstune 会像处理粘贴的链接一样查找这首歌。它还会用这个 ID 向 Apple 查询这段录音的时长，让找到的歌词与这段录音的时间对齐；跟着听时识别出的每首歌也一样。和其他请求一样，此请求会让 Shazam 看到你的 IP 地址，Shazam 按其自己的隐私政策处理。如果 Crosstune 无法连接 Shazam，会改为打开 Shazam 应用或 Google 应用（如果你装了），它们按各自的隐私政策收听。

歌词也可以一起聆听：在 Crosstune 刚识别出一首歌之后，或在你点按歌词中的麦克风时。歌词显示期间，Crosstune 会以同样的方式继续聆听，每隔几秒向 Shazam 发送新的声纹，从不发送音频，以便跟上歌曲的节奏并识别下一首。只要你关闭歌词、关掉此功能或离开应用，聆听就会立即停止。歌词悬浮在其他应用上方时，会一直聆听，直到你关闭它。 如果已允许使用麦克风，歌词可短暂聆听，以校正并记住该录音片头造成的时间偏移。它听的是手机播放的声音，戴耳机也行；只有手机不共享声音时才用麦克风。在内存为 3 GB 或以上的手机上，歌词还会每次聆听手机播放的 20 秒声音，找出每一行唱出的时间并移到那里：歌曲第一次从头播放时贯穿整首歌，从中途播放或在歌曲中跳转时则每次聆听一次。这在你的手机上完成，声音不会被保存或发送。所用的语音模型（whisper.cpp 的模型）只在 Wi-Fi 或其他不按流量计费的网络下，从 Hugging Face 下载一次；和其他请求一样，这会让 Hugging Face 看到你的 IP 地址。

ChatGPT

Crosstune 的 AI 功能是可选的，只有在你用自己的付费 ChatGPT 套餐登录后才能使用。登录在浏览器中的 OpenAI 网站上完成。Crosstune 把登录信息保存在你的手机上，不纳入备份，并且只发送给 OpenAI。退出登录后即删除。

登录期间，Crosstune 会把每个功能所需的内容发送给 OpenAI：歌曲的标题、艺人和歌词，用于翻译或讲解、修正日语读音、把以拉丁字母找到的歌词写成日文或韩文，或挑出值得学的词；一个词及其所在的行，用于查词；你对某一行或某首歌提出的问题；以及你输入的描述或一首歌，用于找到相符的歌曲。OpenAI 按其自身的隐私政策处理这些内容，并计入你套餐的用量。

打开一首歌的释义时，Crosstune 还会把歌名和歌手发送给 MusicBrainz（MetaBrainz 运营的音乐数据库，无需账号或密钥），以获取发行年份和专辑，让释义每次给出相同的内容。它的回答会保存在你的手机上，所以每首歌只会查询一次。

投放到电视

在 Google Play 和 GitHub 版本中，你可以把歌曲投放到 Android TV 或 Google TV 上的 Crosstune。Google Cast 是 Google Play 服务的一部分，它在你的本地网络中查找电视并负责投放。投放时，Crosstune 会把歌曲的标题、艺人、链接和封面发给电视，之后再发你的操作：暂停、播放、跳过、拖动、翻译和注音。电视会告诉你的手机它正在播放什么。这些只在你的手机和电视之间传递，绝不会发给开发者，Google 按其自己的隐私政策处理。没有 Google Play 服务的版本没有投放功能，也不会发送此类内容。

权限与安全

Crosstune 使用 Android 的网络权限来获取音乐信息和封面图片，并读取网络状态以判断手机何时离线。第一次识别歌曲或打开歌词时，它会请求麦克风权限，并且只在聆听期间使用麦克风。如果你让歌词悬浮在其他应用上方，应用会请求显示在其他应用上层的权限，并请求一次显示通知的权限。通知会让歌词保持显示，并可用来解锁或关闭。它不会请求位置、相机、通讯录或广告 ID 权限。内置的音乐服务请求均使用 HTTPS。如果你自行添加应用或网站，请选择可信的 HTTPS 地址。MilkDrop 视觉效果同样使用麦克风权限，通过 Android 读取手机正在播放的声音；这些声音不会被录制，也不会发送到任何地方。如果你使用 Shizuku 或 root，点按“一键设置”或“全部修复”会请求其权限，Crosstune 仅用它来替你更改 Android 的链接设置、麦克风权限、歌词的访问权限，以及显示在其他应用上层的权限。

保留与删除

你可以在应用中清除最近的历史记录。在 Android 设置中清除 Crosstune 的应用存储空间，会删除其本地设置和历史记录。开发者没有任何需要删除的服务器端账号或收听记录。第三方音乐服务已经收到的请求，适用这些服务各自的保留和删除政策。报告里没有任何能看出是谁发送的信息，所以无法按请求找到某份报告来删除。每份报告会在 180 天后删除。

儿童

Crosstune 不会询问用户的年龄或个人资料信息，也不会在开发者运营的服务器上有意收集儿童的个人信息。所链接的音乐服务有各自的年龄要求和隐私政策。父母和监护人应在孩子使用这些服务前先查看相关内容。

联系方式与变更

如有隐私方面的问题，请联系 crosstune@4st.li。如果你给开发者发送电子邮件，电子邮件服务会处理你的地址和邮件内容，以便开发者回复。请不要包含无需分享的敏感信息。

在歌词里点“报告问题”，再点“发送”，会把你写的内容、Crosstune 和 Android 的版本，以及这首歌的歌名、歌手和时长、歌词的来源和对时方式、你手动对时的行和 Crosstune 正在跟随的应用发送到开发者的服务器。服务器运行在 Cloudflare 上，Cloudflare 按自己的隐私政策处理这次连接，包括你的 IP 地址。服务器不保存你的 IP 地址。只有开发者会看报告，报告绝不会公开。如果你在设置中打开“自动报告歌曲问题”，或在 Crosstune 提出时选择“好”，Crosstune 会在发现歌曲没有歌词、没有时间或没有和弦时，在你手动为歌词对时后，或在听到的演唱与歌词对不上时，发送同样的信息，不含评论。每首歌的每个问题只发送一次，你可以随时在设置中关闭。在设置中，“报告问题”则会打开一个已填好 Crosstune 和 Android 版本的 GitHub issue 或邮件，你可以修改后自己发送，GitHub 或你的邮件服务会按各自的隐私政策处理。

当应用的行为发生变化时，本政策可能会更新。更新内容将发布在此页面上，并注明新的日期。
