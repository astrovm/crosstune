Crosstune 隐私政策

最后更新：2026年10月22日

简要说明

  • 没有账号、广告或数据分析。
  • Crosstune 没有服务器。你的历史记录只保存在你的手机上。
  • 你转换的链接只会发送到相关的音乐服务。
  • 识别歌曲时，Shazam 只会收到声音的指纹，绝不会收到音频。
  • 随时可以在应用中清除历史记录。
  • AI 功能是可选的。只有在你用 ChatGPT 登录后，才会把歌词发送给 OpenAI。

详细说明

Crosstune 是由 astrovm 开发的 Android 应用，可以在你选择的音乐应用或网站中打开音乐链接。本政策说明应用会使用哪些信息，以及这些信息会发送到哪里。

没有账号、广告或数据分析

Crosstune 不需要账号，也不包含广告、数据分析或崩溃报告服务。开发者没有运营任何接收你的音乐链接或收听记录的服务器。Crosstune 不会出售你的信息。

你设备上的信息

应用会在你的设备上保存你的设置和最近解析的链接。最近的条目可能包括来源链接、标题、艺人、封面网址以及准备好的目标链接。这些偏好设置和历史记录不在应用的 Android 云备份和设备迁移规则范围内。

Crosstune 会读取你粘贴的链接、分享给它的链接，或通过 Android 链接处理打开的链接。它的剪贴板快捷方式会在你使用时读取剪贴板中的文字。它会检查设备上安装了哪些支持的音乐应用，以便将它们作为目标提供给你。这些信息只保留在你的设备上。

向音乐服务发出的请求

为了解析音乐链接，Crosstune 会向来源服务请求其公开页面或公开 API。它还会从该服务的图片服务器加载封面图片。支持的来源服务包括 Spotify、YouTube、YouTube Music、Apple Music、Deezer、TIDAL、SoundCloud、Bandcamp 和 Audiomack。 Shazam 链接通过 Apple Music 的查询读取，较早的链接会先通过 Shazam 的公开 API 读取。 分享的 Google 结果会在 Google 上打开，以读取歌曲名称。

开启“打开精确匹配”后，应用会将该项目的标题和艺人发送到目标的搜索服务：Apple Music、Deezer、YouTube Music、YouTube、Bandcamp、TIDAL、SoundCloud、Audiomack 或 Qobuz。你可以在设置中关闭此选项。当你打开目标时，所选应用或网站会收到目标链接或搜索词。在播放列表或专辑中使用“全部播放”时，应用会将每首歌曲的标题和艺人发送到 YouTube Music 的搜索，然后将找到的视频列表发送到 YouTube，YouTube 会返回一个临时播放列表。你自行添加的应用和网站会通过你配置的网址模板收到搜索词。分享结果时，结果会发送给你选择的应用或接收者。

当你输入歌曲名称而不是链接时，Crosstune 会将该名称发送到 Deezer 和 Apple 的公开歌曲搜索，并显示找到的歌曲，这样即使没有链接也能打开你要的歌曲。当你请求某首歌曲的歌词或和弦时，应用会将歌曲的标题和艺人发送到无需账号或密钥的服务：歌词用 LRCLIB、YouTube Music、网易云音乐和 Letras，和弦用 Ultimate Guitar、LaCuerda 和 U-FRET，并用 Apple 的歌曲搜索查找歌曲的原名。在歌词中开启翻译后，应用会把歌词各行发送给无需账号的翻译服务 Google Translate，Google Translate 无法翻译时则发送给同样无需账号的 MyMemory，除非如下文所述由 ChatGPT 翻译。歌曲的语言由 Android 在你的手机上识别，已经是翻译目标语言的歌词，或是你选择不翻译的语言的歌词，都不会被发送。汉字上方假名等读音在你的手机上生成，不会发送到任何地方。你点按查看意思的词也会以同样方式发送。如果应用语言是英语，英文单词会在 Wiktionary 词典中查询。你保存的行只留在手机上。

如果你让歌词跟随音乐应用中正在播放的歌曲，Android 会请你允许 Crosstune 的通知使用权。Crosstune 只用它来查看你的音乐应用正在播放哪首歌以及播放到哪里，让歌词跟着走，并让你点按的那一行把歌曲跳到那里。它从不读取你的通知，这些信息也不会离开你的手机。你可以随时在 Android 设置中关闭它。当你练习已保存的行时，Crosstune 还会请你的音乐应用从那一行开始播放它所在的歌曲。Crosstune 的播放器使用同样的权限来显示歌曲，并在你的音乐应用里暂停、切歌或跳转进度。

与其他网络请求一样，这些请求会让被访问的服务看到你的 IP 地址和常规请求信息。这些服务可能会保留请求日志，并按照各自的隐私政策处理信息。开发者无法控制它们如何处理或保存这些数据。打开音乐服务后，该服务可能会要求使用其自己的账号或订阅。

歌曲识别

当你让 Crosstune 识别歌曲时，它只在聆听期间通过麦克风录音，最长 12 秒，一找到歌曲就停止。声音会在你的手机上转换成由最响亮的点组成的指纹。发送给 Shazam 的只有这个指纹，绝不包括音频，录音也不会保存。Crosstune 不会发送你的位置。Shazam 会返回歌曲的标题、艺人、封面和 Apple Music ID，然后 Crosstune 会像处理粘贴的链接一样查找这首歌。和其他请求一样，此请求会让 Shazam 看到你的 IP 地址，Shazam 按其自己的隐私政策处理。你可以在设置中改用 Shazam 或 Google 应用来识别歌曲，它们按各自的隐私政策收听。

歌词也可以一起聆听：在 Crosstune 刚识别出一首歌之后，或在你点按歌词中的麦克风时。歌词显示期间，Crosstune 会以同样的方式继续聆听，每隔几秒向 Shazam 发送新的声纹，从不发送音频，以便跟上歌曲的节奏并识别下一首。只要你关闭歌词、关掉此功能或离开应用，聆听就会立即停止。歌词悬浮在其他应用上方时，会一直聆听，直到你关闭它。 如果已允许使用麦克风，视频歌词可短暂聆听，以校正并记住该录音片头造成的时间偏移。

ChatGPT

Crosstune 的 AI 功能是可选的，只有在你用自己的付费 ChatGPT 套餐登录后才能使用。登录在浏览器中的 OpenAI 网站上完成。Crosstune 把登录信息保存在你的手机上，不纳入备份，并且只发送给 OpenAI。退出登录后即删除。

登录期间，Crosstune 会把每个功能所需的内容发送给 OpenAI：歌曲的标题、艺人和歌词，用于翻译或讲解、修正日语读音、把以罗马字找到的歌词写成日文，或挑出值得学的词；一个词及其所在的行，用于查词；你对某一行或某首歌提出的问题；以及你输入的描述或一首歌，用于找到相符的歌曲。OpenAI 按其自身的隐私政策处理这些内容，并计入你套餐的用量。

权限与安全

Crosstune 使用 Android 的网络权限来获取音乐信息和封面图片。第一次识别歌曲时，它会请求麦克风权限，并且只在聆听期间使用麦克风。如果你让歌词悬浮在其他应用上方，应用会请求显示在其他应用上层的权限，并请求一次显示通知的权限。通知会让歌词保持显示，并可用来解锁或关闭。它不会请求位置、相机、通讯录或广告 ID 权限。内置的音乐服务请求均使用 HTTPS。如果你自行添加应用或网站，请选择可信的 HTTPS 地址。MilkDrop 视觉效果同样使用麦克风权限，通过 Android 读取手机正在播放的声音；这些声音不会被录制，也不会发送到任何地方。如果你使用 Shizuku，点按“一键设置”会请求 Shizuku 的权限，Crosstune 仅用它来替你更改 Android 的链接设置和歌词的访问权限。

保留与删除

你可以在应用中清除最近的历史记录。在 Android 设置中清除 Crosstune 的应用存储空间，会删除其本地设置和历史记录。开发者没有任何需要删除的服务器端账号或收听记录。第三方音乐服务已经收到的请求，适用这些服务各自的保留和删除政策。

儿童

Crosstune 不会询问用户的年龄或个人资料信息，也不会在开发者运营的服务器上有意收集儿童的个人信息。所链接的音乐服务有各自的年龄要求和隐私政策。父母和监护人应在孩子使用这些服务前先查看相关内容。

联系方式与变更

如有隐私方面的问题，请联系 crosstune@4st.li。如果你给开发者发送电子邮件，电子邮件服务会处理你的地址和邮件内容，以便开发者回复。请不要包含无需分享的敏感信息。

在歌词或设置中点“报告问题”，会打开一个 GitHub issue 或一封邮件，已预先填好 Crosstune 和 Android 的版本，如果是关于某首歌，还有歌名和歌手、歌词是否带时间或由你手动对时，以及 Crosstune 正在跟随的应用。发送前你可以修改。除非你自己发送，否则不会发送任何内容，GitHub 或你的邮件服务会按各自的隐私政策处理。

当应用的行为发生变化时，本政策可能会更新。更新内容将发布在此页面上，并注明新的日期。
