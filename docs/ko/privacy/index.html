Crosstune 개인정보처리방침

최종 업데이트: 2026년 10월 4일

요약

  • 계정, 광고, 분석이 없어요.
  • Crosstune 서버는 없어요. 기록은 휴대폰에만 남아요.
  • 변환하는 링크는 관련된 음악 서비스에만 전달돼요.
  • 앱에서 언제든 기록을 삭제할 수 있어요.

자세한 내용

Crosstune은 astrovm이 개발한 Android 앱으로, 음악 링크를 사용자가 선택한 음악 앱이나 웹사이트에서 열어요. 이 방침은 앱이 어떤 정보를 사용하고 그 정보가 어디로 가는지 설명해요.

계정, 광고, 분석 없음

Crosstune은 계정이 필요 없고 광고, 분석, 비정상 종료 보고 서비스를 포함하지 않아요. 개발자는 음악 링크나 감상 기록을 받는 서버를 운영하지 않아요. Crosstune은 사용자의 정보를 판매하지 않아요.

기기에 저장되는 정보

앱은 설정과 최근 처리한 링크를 기기에 저장해요. 최근 항목에는 원본 링크, 제목, 아티스트, 커버 이미지 URL, 미리 준비한 대상 링크가 포함될 수 있어요. 이 설정과 기록은 앱의 Android 클라우드 백업 및 기기 간 전송 규칙에서 제외돼요.

Crosstune은 사용자가 붙여넣거나, 앱으로 공유하거나, Android 링크 처리를 통해 연 링크를 읽어요. 클립보드 바로가기는 사용자가 실행할 때 클립보드의 텍스트를 읽어요. 대상으로 제안할 수 있도록 지원되는 음악 앱 중 어떤 앱이 설치되어 있는지 확인해요. 이 정보는 기기에만 남아요.

음악 서비스로 보내는 요청

음악 링크를 처리하기 위해 Crosstune은 원본 서비스에 공개 페이지나 공개 API를 요청해요. 또한 해당 서비스의 이미지 서버에서 커버 이미지를 불러와요. 지원되는 원본 서비스에는 Spotify, YouTube, YouTube Music, Apple Music, Deezer, TIDAL, SoundCloud, Bandcamp, Audiomack이 있어요. Shazam 링크는 Apple Music 검색으로 읽고, 오래된 링크는 먼저 Shazam의 공개 API로 읽어요.

‘정확한 항목 열기’를 켜면 앱이 항목의 제목과 아티스트를 대상 서비스의 검색으로 보내요. 대상 서비스는 Apple Music, Deezer, YouTube Music, YouTube, Bandcamp예요. 이 옵션은 설정에서 끌 수 있어요. 대상을 열면 선택한 앱이나 웹사이트가 대상 링크나 검색어를 받아요. 플레이리스트나 앨범에서 ‘모두 재생’을 쓰면 앱이 각 노래의 제목과 아티스트를 YouTube Music 검색으로 보내고, 찾은 동영상 목록을 YouTube로 보내요. 그러면 YouTube가 임시 플레이리스트를 돌려줘요. 직접 추가한 앱과 사이트는 사용자가 설정한 URL 템플릿으로 검색어를 받아요. 결과를 공유하면 사용자가 선택한 앱이나 받는 사람에게 전송돼요.

다른 인터넷 요청과 마찬가지로 이 요청을 통해 IP 주소와 일반적인 요청 정보가 연결된 서비스에 전달돼요. 이 서비스들은 요청 로그를 보관하고 자체 개인정보처리방침에 따라 정보를 처리할 수 있어요. 개발자는 이들이 데이터를 처리하거나 보관하는 방식을 관리하지 않아요. 음악 서비스를 연 뒤에 해당 서비스의 계정이나 구독이 필요할 수 있어요.

권한 및 보안

Crosstune은 음악 정보와 커버 이미지를 가져오기 위해 Android의 인터넷 권한을 사용해요. 위치, 마이크, 카메라, 연락처, 광고 ID 권한은 요청하지 않아요. 기본 제공되는 음악 서비스 요청은 HTTPS를 사용해요. 앱이나 사이트를 직접 추가한다면 신뢰할 수 있는 HTTPS 주소를 선택하세요. 노래 인식 버튼은 Shazam이나 Google 앱을 열며, 이 앱들은 각자의 개인정보처리방침에 따라 소리를 들어요. Crosstune은 마이크를 사용하지 않아요.

보관 및 삭제

앱에서 최근 기록을 삭제할 수 있어요. Android 설정에서 Crosstune의 앱 저장공간을 지우면 기기에 저장된 설정과 기록이 삭제돼요. 개발자는 삭제할 서버 측 계정이나 감상 기록을 보유하고 있지 않아요. 서드파티 음악 서비스가 이미 받은 요청에는 해당 서비스의 보관 및 삭제 정책이 적용돼요.

어린이

Crosstune은 사용자에게 나이나 개인 프로필 정보를 묻지 않으며, 개발자가 운영하는 서버에서 어린이의 개인정보를 고의로 수집하지 않아요. 연결된 음악 서비스에는 각자의 연령 요건과 개인정보처리방침이 있어요. 부모와 보호자는 어린이가 이용하기 전에 이를 확인해 주세요.

문의 및 변경

개인정보 관련 문의는 ~@4st.li로 연락해 주세요. 개발자에게 이메일을 보내면 개발자가 답장할 수 있도록 이메일 서비스가 사용자의 주소와 메시지를 처리해요. 공유할 필요가 없는 민감한 정보는 포함하지 마세요.

앱의 작동 방식이 바뀌면 이 방침이 업데이트될 수 있어요. 업데이트 내용은 새 날짜와 함께 이 페이지에 게시돼요.
