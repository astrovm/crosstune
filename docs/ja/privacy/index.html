Crosstune プライバシーポリシー

最終更新日: 2026年10月8日

概要

  • アカウント、広告、解析はありません。
  • Crosstune のサーバーはありません。履歴はスマートフォンの中だけに残ります。
  • 変換したリンクは、関係する音楽サービスにのみ送られます。
  • 曲の認識では、Shazam に送るのは音のフィンガープリントだけで、音声そのものは送りません。
  • 履歴はアプリでいつでも消去できます。

詳細

Crosstune は astrovm が開発した Android アプリで、音楽リンクを選んだ音楽アプリまたはウェブサイトで開きます。このポリシーでは、アプリが使う情報とその送信先について説明します。

アカウント、広告、解析なし

Crosstune はアカウントを必要とせず、広告、解析、クラッシュレポートのサービスも含みません。開発者は、音楽リンクや再生履歴を受け取るサーバーを運営していません。Crosstune があなたの情報を販売することはありません。

端末内の情報

アプリは、設定と最近処理したリンクを端末内に保存します。最近の項目には、元のリンク、タイトル、アーティスト、カバー画像の URL、用意した開き先のリンクが含まれることがあります。これらの設定と履歴は、アプリの Android クラウドバックアップと端末間転送のルールから除外されています。

Crosstune は、貼り付けたリンク、共有したリンク、Android のリンク処理を通じて開いたリンクを読み取ります。クリップボードのショートカットは、使ったときにクリップボードのテキストを読み取ります。開き先として提案できるよう、対応する音楽アプリのうちどれがインストールされているかを確認します。これらの情報は端末内にとどまります。

音楽サービスへのリクエスト

音楽リンクを処理するため、Crosstune はリンク元のサービスに公開ページまたは公開 API をリクエストします。また、そのサービスの画像サーバーからカバー画像を読み込みます。対応するリンク元のサービスには、Spotify、YouTube、YouTube Music、Apple Music、Deezer、TIDAL、SoundCloud、Bandcamp、Audiomack があります。 Shazam のリンクは Apple Music の検索で読み取ります。古いリンクはまず Shazam の公開 API で読み取ります。 共有された Google の検索結果は、曲名を読み取るために Google で開きます。

「一致する項目を直接開く」がオンのときは、項目のタイトルとアーティストを開き先の検索サービス (Apple Music、Deezer、YouTube Music、YouTube、Bandcamp) に送信します。このオプションは設定でオフにできます。開き先を開くと、選んだアプリやウェブサイトが開き先のリンクまたは検索語を受け取ります。プレイリストやアルバムで「すべて再生」を使うと、各曲のタイトルとアーティストを YouTube Music の検索に送信し、見つかった動画のリストを YouTube に送信します。YouTube からは一時的なプレイリストが返されます。自分で追加したアプリやサイトは、設定した URL テンプレートで検索語を受け取ります。結果を共有すると、選んだアプリや相手に送信されます。

リンクの代わりに曲名を入力すると、Crosstune はその名前を Deezer と Apple の公開曲検索に送信し、見つかった曲を表示します。リンクがなくても目的の曲を開けます。曲の歌詞を求めると、アプリは曲のタイトルとアーティストを LRCLIB に送信します。LRCLIB はアカウントやキーが不要な歌詞サービスです。

音楽アプリで再生中の曲に歌詞を合わせる場合、Android から Crosstune への通知へのアクセスの許可を求められます。Crosstune はこれを、音楽アプリが再生中だと伝えている曲とその再生位置を知るためだけに使い、歌詞を曲に合わせて進めたり、タップした行に曲を移動したりします。通知の内容を読むことはなく、これらの情報が端末の外に出ることもありません。いつでも Android の設定でオフにできます。

ほかのインターネット通信と同じく、これらのリクエストでは IP アドレスと通常のリクエスト情報が接続先のサービスに伝わります。これらのサービスは、リクエストのログを保存し、それぞれのプライバシーポリシーに従って情報を処理することがあります。開発者は、それらのデータの処理方法や保存方法を管理していません。音楽サービスによっては、開いたあとに専用のアカウントや有料プランが必要になることがあります。

曲の認識

Crosstune に曲を認識させると、聞き取っている間だけ、最大 12 秒間マイクで録音し、曲が見つかった時点で止めます。音は端末内で、特に大きな音の点を集めたフィンガープリントに変換されます。Shazam に送るのはこのフィンガープリントだけで、音声そのものは送らず、録音も保存しません。位置情報は送りません。Shazam は曲のタイトル、アーティスト、カバー画像、Apple Music の ID を返し、Crosstune はその曲を貼り付けたリンクと同じように調べます。ほかのリクエストと同じく、このリクエストでも IP アドレスが Shazam に伝わり、Shazam は自身のプライバシー ポリシーに従ってそれを処理します。設定で、曲の認識に Shazam または Google アプリを選ぶこともできます。その場合、それぞれのプライバシー ポリシーに従って音を聞き取ります。

歌詞は一緒に聞くこともできます。Crosstune が曲を認識した直後、または歌詞画面のマイクをタップしたときです。歌詞が画面に表示されている間、Crosstune は同じ方法で聞き続け、曲に合わせ続けて次の曲を捉えるために、数秒ごとに音声ではなく新しいフィンガープリントを Shazam に送ります。歌詞を閉じる、オフにする、またはアプリを離れると、すぐに聞くのをやめます。

権限とセキュリティ

Crosstune は、音楽の情報とカバー画像を取得するために Android のインターネット権限を使います。初めて曲を認識するときにマイクの権限を求め、マイクは聞き取っている間だけ使います。位置情報、カメラ、連絡先、広告 ID の権限は求めません。音楽サービスへの組み込みのリクエストには HTTPS を使います。自分でアプリやサイトを追加する場合は、信頼できる HTTPS アドレスを選んでください。

保存と削除

最近の履歴はアプリで消去できます。Android の設定で Crosstune のアプリのストレージを消去すると、端末内の設定と履歴が削除されます。開発者は、削除の対象となるサーバー上のアカウントや再生履歴の記録を持っていません。サードパーティの音楽サービスがすでに受け取ったリクエストには、そのサービスの保存と削除のポリシーが適用されます。

お子様について

Crosstune は、ユーザーに年齢や個人のプロフィール情報を尋ねることはなく、開発者が運営するサーバーで子どもの個人情報を意図的に収集することもありません。連携する音楽サービスには、それぞれ独自の年齢要件とプライバシーポリシーがあります。お子様が利用する前に、保護者の方はそれらをご確認ください。
