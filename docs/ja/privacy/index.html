Crosstune プライバシーポリシー

最終更新日: 2026年10月25日

概要

  • アカウント、広告、解析はありません。
  • Crosstune のサーバーはありません。履歴はスマートフォンの中だけに残ります。
  • 変換したリンクは、関係する音楽サービスにのみ送られます。
  • 曲の認識では、Shazam に送るのは音のフィンガープリントだけで、音声そのものは送りません。
  • 履歴はアプリでいつでも消去できます。
  • AI 機能は任意です。ChatGPT でサインインした後にだけ、歌詞を OpenAI に送信します。

詳細

Crosstune は astrovm が開発した Android アプリで、音楽リンクを選んだ音楽アプリまたはウェブサイトで開きます。このポリシーでは、アプリが使う情報とその送信先について説明します。

アカウント、広告、解析なし

Crosstune はアカウントを必要とせず、広告、解析、クラッシュレポートのサービスも含みません。開発者は、音楽リンクや再生履歴を受け取るサーバーを運営していません。Crosstune があなたの情報を販売することはありません。

端末内の情報

アプリは、設定と最近処理したリンクを端末内に保存します。最近の項目には、元のリンク、タイトル、アーティスト、カバー画像の URL、用意した開き先のリンクが含まれることがあります。これらの設定と履歴は、アプリの Android クラウドバックアップと端末間転送のルールから除外されています。

Crosstune は、貼り付けたリンク、共有したリンク、Android のリンク処理を通じて開いたリンクを読み取ります。クリップボードのショートカットは、使ったときにクリップボードのテキストを読み取ります。開き先として提案できるよう、対応する音楽アプリのうちどれがインストールされているかを確認します。これらの情報は端末内にとどまります。

音楽サービスへのリクエスト

音楽リンクを処理するため、Crosstune はリンク元のサービスに公開ページまたは公開 API をリクエストします。また、そのサービスの画像サーバーからカバー画像を読み込みます。対応するリンク元のサービスには、Spotify、YouTube、YouTube Music、Apple Music、Deezer、TIDAL、SoundCloud、Bandcamp、Audiomack があります。 Shazam のリンクは Apple Music の検索で読み取ります。古いリンクはまず Shazam の公開 API で読み取ります。 共有された Google の検索結果は、曲名を読み取るために Google で開きます。

項目そのものを開くため、項目のタイトルとアーティストを開き先の検索サービス (Apple Music、Deezer、YouTube Music、YouTube、Bandcamp、TIDAL、SoundCloud、Audiomack、Qobuz) に送信します。リンクをアプリで直接開き、「すぐに再生」がオフのときは、代わりにそのアプリで検索が開き、何も送信されません。開き先を開くと、選んだアプリやウェブサイトが開き先のリンクまたは検索語を受け取ります。プレイリストやアルバムで「すべて再生」を使うと、各曲のタイトルとアーティストを YouTube Music の検索に送信し、見つかった動画のリストを YouTube に送信します。YouTube からは一時的なプレイリストが返されます。自分で追加したアプリやサイトは、設定した URL テンプレートで検索語を受け取ります。結果を共有すると、選んだアプリや相手に送信されます。

リンクの代わりに曲名を入力すると、Crosstune はその名前を Deezer と Apple の公開曲検索に送信し、見つかった曲を表示します。リンクがなくても目的の曲を開けます。曲の歌詞やコードを求めると、アプリは曲のタイトルとアーティストを、アカウントやキーが不要なサービスに送信します。歌詞は LRCLIB、YouTube Music、NetEase Cloud Music、Letras、コードは Ultimate Guitar、LaCuerda、U-FRET、そして曲の元の名前を調べるための Apple の曲検索です。歌詞で翻訳をオンにすると、アプリは歌詞の各行を、アカウント不要の翻訳サービス Google Translate に送信し、Google Translate で翻訳できないときは、同じくアカウント不要の MyMemory に送信します。ただし、下で説明するように ChatGPT が翻訳する場合は除きます。曲の言語は Android がスマートフォン上で判別し、翻訳先と同じ言語の歌詞や、翻訳しないと選んだ言語の歌詞は送信されません。漢字の上のかななどの読みはスマートフォン上で作られ、どこにも送信されません。意味を調べるためにタップした単語も同じように送信されます。アプリが英語の場合、英語の単語は Wiktionary の辞書で調べます。保存した行はスマートフォンに残ります。

音楽アプリで再生中の曲に歌詞を合わせる場合、Android から Crosstune への通知へのアクセスの許可を求められます。Crosstune はこれを、音楽アプリが再生中だと伝えている曲とその再生位置を知るためだけに使い、歌詞を曲に合わせて進めたり、タップした行に曲を移動したりします。通知の内容を読むことはなく、これらの情報が端末の外に出ることもありません。いつでも Android の設定でオフにできます。保存した行を練習するとき、Crosstune は音楽アプリに、その行の曲をその行から再生するようにも頼みます。Crosstune のプレーヤーも同じアクセスを使い、曲を表示して、音楽アプリでの一時停止、スキップ、再生位置の移動を行います。

ほかのインターネット通信と同じく、これらのリクエストでは IP アドレスと通常のリクエスト情報が接続先のサービスに伝わります。これらのサービスは、リクエストのログを保存し、それぞれのプライバシーポリシーに従って情報を処理することがあります。開発者は、それらのデータの処理方法や保存方法を管理していません。音楽サービスによっては、開いたあとに専用のアカウントや有料プランが必要になることがあります。

曲の認識

Crosstune に曲を認識させると、聞き取っている間だけ、最大 12 秒間マイクで録音し、曲が見つかった時点で止めます。音は端末内で、特に大きな音の点を集めたフィンガープリントに変換されます。Shazam に送るのはこのフィンガープリントだけで、音声そのものは送らず、録音も保存しません。位置情報は送りません。Shazam は曲のタイトル、アーティスト、カバー画像、Apple Music の ID を返し、Crosstune はその曲を貼り付けたリンクと同じように調べます。ほかのリクエストと同じく、このリクエストでも IP アドレスが Shazam に伝わり、Shazam は自身のプライバシー ポリシーに従ってそれを処理します。Crosstune が Shazam に接続できないときは、代わりに Shazam アプリか Google アプリを開きます（入っている場合）。その場合、それぞれのプライバシー ポリシーに従って音を聞き取ります。

歌詞は一緒に聞くこともできます。Crosstune が曲を認識した直後、または歌詞画面のマイクをタップしたときです。歌詞が画面に表示されている間、Crosstune は同じ方法で聞き続け、曲に合わせ続けて次の曲を捉えるために、数秒ごとに音声ではなく新しいフィンガープリントを Shazam に送ります。歌詞を閉じる、オフにする、またはアプリを離れると、すぐに聞くのをやめます。歌詞が他のアプリの上に表示されている間は、閉じるまで聞き続けます。 マイクの使用が許可済みの場合、歌詞は短時間音を聴いて、その録音のイントロによるずれを補正し、記憶できます。スマホが再生している音を聴くので、ヘッドホンでも使えます。スマホが音を共有しない場合のみマイクを使います。メモリが 3 GB 以上のスマホでは、歌詞は曲ごとに一度、スマホが再生している音を 20 秒聴いて、歌詞が歌われるタイミングを見つけ、そこへ合わせます。これはスマホの中で行われ、音は保存も送信もされません。使う音声モデル（whisper.cpp のもの）は、Wi-Fi などの従量制でないネットワークでのみ、Hugging Face から一度だけダウンロードされます。ほかのリクエストと同じく、IP アドレスが Hugging Face に伝わります。

ChatGPT

Crosstune の AI 機能は任意で、ご自身の有料 ChatGPT プランでサインインした後にだけ動作します。サインインはブラウザで OpenAI のサイト上で行います。Crosstune はサインイン情報をスマートフォンに保存し、バックアップには含めず、OpenAI にだけ送信します。サインアウトすると削除されます。

サインイン中、Crosstune は各機能に必要なものを OpenAI に送信します。曲を翻訳・解説する、日本語の読みを直す、ローマ字で見つかった歌詞を日本語で書く、覚える価値のある単語を選ぶためには、曲のタイトル、アーティスト、歌詞を。単語を調べるためには、その単語と行を。行や曲についての質問を。合う曲を探すためには、入力した説明や曲を。OpenAI はこれらを自社のプライバシーポリシーに従って扱い、プランの利用量に含まれます。

権限とセキュリティ

Crosstune は、音楽の情報とカバー画像を取得するために Android のインターネット権限を使います。初めて曲を認識するときや歌詞を開くときにマイクの権限を求め、マイクは聞き取っている間だけ使います。歌詞を他のアプリの上に表示すると、他のアプリの上に表示する権限と、一度だけ通知を表示する権限を求めます。通知は表示を保ち、ロック解除や終了に使えます。位置情報、カメラ、連絡先、広告 ID の権限は求めません。音楽サービスへの組み込みのリクエストには HTTPS を使います。自分でアプリやサイトを追加する場合は、信頼できる HTTPS アドレスを選んでください。MilkDrop のビジュアルはマイクの権限も使い、Android を通じてスマートフォンが再生している音を読み取ります。その音は録音も送信もされません。Shizuku または root を使っている場合、「すべて設定」または「すべて修正」をタップするとその権限を求めます。Crosstune はそれを、Android のリンク設定、マイクと歌詞のアクセス、他のアプリの上に重ねて表示する権限をあなたの代わりに変更するためだけに使います。

保存と削除

最近の履歴はアプリで消去できます。Android の設定で Crosstune のアプリのストレージを消去すると、端末内の設定と履歴が削除されます。開発者は、削除の対象となるサーバー上のアカウントや再生履歴の記録を持っていません。サードパーティの音楽サービスがすでに受け取ったリクエストには、そのサービスの保存と削除のポリシーが適用されます。

お子様について

Crosstune は、ユーザーに年齢や個人のプロフィール情報を尋ねることはなく、開発者が運営するサーバーで子どもの個人情報を意図的に収集することもありません。連携する音楽サービスには、それぞれ独自の年齢要件とプライバシーポリシーがあります。お子様が利用する前に、保護者の方はそれらをご確認ください。
