Crosstune 隱私政策

最後更新：2026年11月1日

簡要說明

  • 沒有帳號、廣告或資料分析。
  • 你的歷史記錄只儲存在你的手機上。Crosstune 唯一的伺服器只接收你送出的問題回報。
  • 你轉換的連結只會傳送到相關的音樂服務。
  • 辨識歌曲時，Shazam 只會收到聲音的指紋，絕不會收到音訊。
  • 隨時可以在應用程式中清除歷史記錄。
  • AI 功能是選用的。只有在你用 ChatGPT 登入後，才會把歌詞傳送給 OpenAI。

詳細說明

Crosstune 是由 astrovm 開發的 Android 應用程式，可以在你選擇的音樂應用程式或網站中開啟音樂連結。本政策說明應用程式會使用哪些資訊，以及這些資訊會傳送到哪裡。

沒有帳號、廣告或資料分析

Crosstune 不需要帳號，也不包含廣告、資料分析或當機報告服務。開發者沒有營運任何接收你的音樂連結或收聽記錄的伺服器。Crosstune 不會出售你的資訊。開發者唯一的伺服器只接收你選擇送出的問題回報，詳見下文。

你裝置上的資訊

應用程式會在你的裝置上儲存你的設定和最近解析的連結。最近的條目可能包括來源連結、標題、藝人、封面網址以及準備好的目標連結。這些偏好設定和歷史記錄不在應用程式的 Android 雲端備份和裝置遷移規則範圍內。你儲存以便離線使用的歌曲、專輯和播放清單，會把歌詞、翻譯、和弦和封面留在應用程式儲存空間中，直到你移除；只在 Wi-Fi 下下載。

Crosstune 會讀取你貼上的連結、分享給它的連結，或透過 Android 連結處理開啟的連結。它的剪貼簿捷徑會在你使用時讀取剪貼簿中的文字。它會檢查裝置上安裝了哪些支援的音樂應用程式，以便將它們作為目標提供給你。這些資訊只保留在你的裝置上。

向音樂服務發出的請求

為了解析音樂連結，Crosstune 會向來源服務請求其公開頁面或公開 API。它還會從該服務的圖片伺服器載入封面圖片。支援的來源服務包括 Spotify、YouTube、YouTube Music、Apple Music、Deezer、TIDAL、SoundCloud、Bandcamp 和 Audiomack。 Shazam 連結透過 Apple Music 的查詢讀取，較早的連結會先透過 Shazam 的公開 API 讀取。 分享的 Google 結果會在 Google 上開啟，以讀取歌名。

為了直接開啟該項目，應用程式會將該項目的標題和藝人傳送到目標的搜尋服務：Apple Music、Deezer、YouTube Music、YouTube、Bandcamp、TIDAL、SoundCloud、Audiomack 或 Qobuz。Spotify 上的歌曲則透過 ListenBrainz 尋找：歌曲的標題和藝人會傳送到 ListenBrainz，它知道 Spotify 上哪些歌曲叫這個名字，然後讀取這些歌曲在 Spotify 上的公開頁面。ListenBrainz 還不知道的歌曲，會在該藝人最常播放的歌曲中尋找：藝人的名字會傳送到 MusicBrainz，並讀取該藝人在 Spotify 上的公開頁面。如果連結直接在應用程式中開啟且「立即播放」已關閉，則會改為在那裡開啟搜尋，不會傳送任何內容。當你開啟目標時，所選應用程式或網站會收到目標連結或搜尋詞。在播放清單或專輯中使用「全部播放」或「隨機播放」時，應用程式會將每首歌曲的標題和藝人傳送到 YouTube Music 的搜尋，然後將找到的影片清單傳送到 YouTube，YouTube 會傳回一個臨時播放清單。在 Spotify 中，每首歌曲會在輪到它時透過 ListenBrainz 查找。你自行新增的應用程式和網站會透過你設定的網址範本收到搜尋詞。分享結果時，結果會傳送給你選擇的應用程式或接收者。

當你輸入歌名而不是連結時，Crosstune 會將該名稱傳送到 Deezer 和 Apple 的公開歌曲搜尋，並顯示找到的歌曲，這樣即使沒有連結也能開啟你要的歌曲。當你請求某首歌曲的歌詞或和弦時，應用程式會將歌曲的標題和藝人傳送到無需帳號或金鑰的服務：歌詞用 LRCLIB、YouTube Music、網易雲音樂和 Letras，和弦用 Ultimate Guitar、Cifra Club、LaCuerda 和 U-FRET，並用 Apple 的歌曲搜尋和歌曲頁面查找歌曲的原名，或翻唱歌曲的原唱和詞曲作者。在歌詞中開啟翻譯後，應用程式會把歌詞各行傳送給無需帳號的翻譯服務 Google Translate，Google Translate 無法翻譯時則傳送給同樣無需帳號的 MyMemory，除非如下文所述由 ChatGPT 翻譯。歌曲的語言由 Android 在你的手機上判斷，已經是翻譯目標語言的歌詞，或是你選擇不翻譯的語言的歌詞，都不會被傳送。漢字上方假名等讀音在你的手機上產生，不會傳送到任何地方。你輕觸檢視意思的詞也會以同樣方式傳送。如果應用程式語言是英語，英文單詞會在 Wiktionary 字典中查詢。你儲存的行只留在手機上。日語會從 Maven Central 下載一次更大的字典 UniDic，只在 Wi-Fi 或其他不按流量計費的網路上下載；和任何請求一樣，這會讓 Maven Central 看到你的 IP 位址。

如果你讓歌詞跟隨音樂應用程式中正在播放的歌曲，Android 會請你允許 Crosstune 的通知存取權。Crosstune 只用它來檢視你的音樂應用程式正在播放哪首歌以及播放到哪裡，讓歌詞跟著走，並讓你輕觸的那一行把歌曲跳到那裡。它從不讀取你的通知，這些資訊也不會離開你的手機。你可以隨時在 Android 設定中關閉它。當你練習已儲存的行時，Crosstune 還會請你的音樂應用程式從那一行開始播放它所在的歌曲。Crosstune 的播放器使用同樣的權限來顯示歌曲和接下來播放的內容，並在你的音樂應用程式裡暫停、切歌、跳轉進度、隨機播放、重複播放、按應用程式自己的讚，或用睡眠定時暫停。

與其他網路請求一樣，這些請求會讓被訪問的服務看到你的 IP 位址和常規請求資訊。這些服務可能會保留請求記錄，並按照各自的隱私政策處理資訊。開發者無法控制它們如何處理或儲存這些資料。開啟音樂服務後，該服務可能會要求使用其自己的帳號或訂閱。

歌曲辨識

當你讓 Crosstune 辨識歌曲時，它只在聆聽期間透過麥克風錄音，最長 12 秒，一找到歌曲就停止。聲音會在你的手機上轉換成由最響亮的點組成的指紋。傳送給 Shazam 的只有這個指紋，絕不包括音訊，錄音也不會儲存。Crosstune 不會傳送你的位置。Shazam 會傳回歌曲的標題、藝人、封面和 Apple Music ID，然後 Crosstune 會像處理貼上的連結一樣查詢這首歌。它也會用這個 ID 向 Apple 查詢這段錄音的長度，讓找到的歌詞與這段錄音的時間對齊；跟著聽時辨識出的每首歌也一樣。和其他請求一樣，此請求會讓 Shazam 看到你的 IP 位址，Shazam 按其自己的隱私政策處理。如果 Crosstune 無法連線到 Shazam，會改為開啟 Shazam 應用程式或 Google 應用程式（如果你有安裝），它們按各自的隱私政策收聽。 離線時，聽到的聲音只留在應用程式的記憶體中，不會儲存，手機重新連線後，只把它的指紋傳給 Shazam。

歌詞也可以一起聆聽：在 Crosstune 剛辨識出一首歌之後，或在你輕觸歌詞中的麥克風時。歌詞顯示期間，Crosstune 會以同樣的方式繼續聆聽，每隔幾秒向 Shazam 傳送新的聲紋，從不傳送音訊，以便跟上歌曲的節奏並辨識下一首。只要你關閉歌詞、關掉此功能或離開應用程式，聆聽就會立即停止。歌詞懸浮在其他應用程式上方時，會一直聆聽，直到你關閉它。 如果已允許使用麥克風，歌詞可短暫聆聽，以校正並記住該錄音片頭造成的時間偏移。它聽的是手機播放的聲音，戴耳機也行；只有手機不分享聲音時才用麥克風。在記憶體為 3 GB 或以上的手機上，歌詞還會每次聆聽手機播放的 20 秒聲音，找出每一行唱出的時間並移到那裡：歌曲第一次從頭播放時貫穿整首歌，從中途播放或在歌曲中跳轉時則每次聆聽一次。這在你的手機上完成，聲音不會被儲存或傳送。所用的語音模型（whisper.cpp 的模型）只在 Wi-Fi 或其他不按流量計費的網路下，從 Hugging Face 下載一次；和其他請求一樣，這會讓 Hugging Face 看到你的 IP 位址。如果你使用 Shizuku 或 root，歌詞會透過 Android 的播放擷取更清楚地聆聽音樂應用程式播放的聲音，期間會顯示一則通知。這些聲音同樣留在你的手機上。不允許這樣做的應用程式（如 Spotify）會照舊聆聽。

ChatGPT

Crosstune 的 AI 功能是選用的，只有在你用自己的付費 ChatGPT 方案登入後才能使用。登入在瀏覽器中的 OpenAI 網站上完成。Crosstune 把登入資訊儲存在你的手機上，不納入備份，而且只傳送給 OpenAI。登出後即刪除。

登入期間，Crosstune 會把每個功能所需的內容傳送給 OpenAI：歌曲的標題、藝人和歌詞，用於翻譯或解說、修正日語讀音、把以拉丁字母找到的歌詞寫成日文或韓文，或挑出值得學的詞；一個詞及其所在的行，用於查詞；你對某一行或某首歌提出的問題；以及你輸入的描述或一首歌，用於找到相符的歌曲。OpenAI 依其自身的隱私權政策處理這些內容，並計入你方案的用量。

開啟一首歌的釋義時，Crosstune 還會把歌名和歌手傳送給 MusicBrainz（MetaBrainz 營運的音樂資料庫，不需要帳號或金鑰），以取得發行年份和專輯，讓釋義每次給出相同的內容。它的回答會儲存在你的手機上，所以每首歌只會查詢一次。

權限與安全

Crosstune 使用 Android 的網路權限來取得音樂資訊和封面圖片，並讀取網路狀態以判斷手機何時離線。第一次辨識歌曲或開啟歌詞時，它會請求麥克風權限，並且只在聆聽期間使用麥克風。如果你讓歌詞懸浮在其他應用程式上方，應用程式會請求顯示在其他應用程式上層的權限，並請求一次顯示通知的權限。通知會讓歌詞保持顯示，並可用來解鎖或關閉。它不會請求位置、相機、通訊錄或廣告 ID 權限。內建的音樂服務請求均使用 HTTPS。如果你自行新增應用程式或網站，請選擇可信的 HTTPS 網址。MilkDrop 視覺效果同樣使用麥克風權限，透過 Android 讀取手機正在播放的聲音；這些聲音不會被錄製，也不會傳送到任何地方。如果你使用 Shizuku 或 root，輕觸「一鍵設定」或「全部修正」會要求其權限，Crosstune 只用它來替你變更 Android 的連結設定、麥克風的存取權、歌詞的存取權，以及顯示在其他應用程式上層的權限。它也讓歌詞不必 Android 每次詢問，就能聆聽音樂應用程式播放的聲音。

保留與刪除

你可以在應用程式中清除最近的歷史記錄。在 Android 設定中清除 Crosstune 的應用程式儲存空間，會刪除其本機設定和歷史記錄。開發者沒有任何需要刪除的伺服器端帳號或收聽記錄。第三方音樂服務已經收到的請求，適用這些服務各自的保留和刪除政策。回報裡沒有任何能看出是誰送出的資訊，所以無法依要求找到某份回報來刪除。每份回報會在 180 天後刪除。

兒童

Crosstune 不會詢問使用者的年齡或個人資料資訊，也不會在開發者營運的伺服器上有意收集兒童的個人資訊。所連結的音樂服務有各自的年齡要求和隱私政策。父母和監護人應在孩子使用這些服務前先檢視相關內容。

聯絡方式與變更

如有隱私方面的問題，請聯絡 crosstune@4st.li。如果你給開發者傳送電子郵件，電子郵件服務會處理你的電子郵件地址和郵件內容，以便開發者回覆。請不要包含無需分享的敏感資訊。

在歌詞裡點「回報問題」，再點「傳送」，會把你寫的內容、Crosstune 和 Android 的版本，以及這首歌的歌名、歌手和長度、歌詞的來源和對時方式、你手動對時的行和 Crosstune 正在跟隨的應用程式傳送到開發者的伺服器。伺服器運行在 Cloudflare 上，Cloudflare 依自己的隱私權政策處理這次連線，包括你的 IP 位址。伺服器不保存你的 IP 位址。只有開發者會看回報，回報絕不會公開。如果你在設定中開啟「自動回報歌曲問題」，或在 Crosstune 提出時選擇「好」，Crosstune 會在發現歌曲沒有歌詞、沒有時間或沒有和弦時，在你手動為歌詞對時後，或在聽到的演唱與歌詞對不上時，傳送同樣的資訊，不含留言。每首歌的每個問題只傳送一次，你可以隨時在設定中關閉。在設定中，「回報問題」則會開啟一個已填好 Crosstune 和 Android 版本的 GitHub issue 或郵件，你可以修改後自己送出，GitHub 或你的郵件服務會依各自的隱私權政策處理。

當應用程式的行為發生變化時，本政策可能會更新。更新內容將發布在此頁面上，並註明新的日期。
